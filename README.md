# Exemplos de interface com React

Aplicação pequena montada com React e Vite, com componentes reutilizáveis, rotas, formulários e exemplos de estado e consumo de API.

## Conteúdo

- Componentes e props
- Estado com useState e efeitos com useEffect
- Navegação com React Router
- Requisições fetch
- Estilização com CSS e Bootstrap

## Como executar

    cd rock-in-rio-doce
    npm install
    npm run dev
